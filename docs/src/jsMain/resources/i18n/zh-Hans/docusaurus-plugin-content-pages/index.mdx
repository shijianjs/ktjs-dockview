<ktjs-features section-title="封装了什么" tinted>

<ktjs-feature icon="lucide:layout-dashboard" title="dock、分栏、网格、窗格">`createDockview`、`createSplitview`、`createGridview`、`createPaneview`——上游导出的四种布局，各自返回带类型的 API。</ktjs-feature>

<ktjs-feature icon="lucide:panel-top" title="面板与分组">`addPanel`、`getPanel`、`removePanel`、`addGroup`、`maximizeGroup`——`DockviewApi` 的每个成员都在，不用 dynamic。</ktjs-feature>

<ktjs-feature icon="lucide:puzzle" title="Kotlin 类能直接实现的渲染器">`IContentRenderer` 是接口，`class PanelRenderer : IContentRenderer` 就是普通 Kotlin；`init` 同时拿到面板自己和整个 dock 的 API。</ktjs-feature>

<ktjs-feature icon="lucide:radio" title="事件就是函数类型">`onDidAddPanel.listen { }` 返回 disposer；上游的可调用 `Event<T>` 在这里是函数类型，不再用类包一层。</ktjs-feature>

<ktjs-feature icon="lucide:palette" title="主题是值">`themeDark`、`themeLight` 等 18 个是带 `className` 与 `colorScheme` 的导出对象，写错名字就编译不过。</ktjs-feature>

<ktjs-feature icon="lucide:book-open" title="双语文档">本站本身是一个 Kotlin/JS 模块，由 ktjs-docusaurus 构建：类型化配置、Markdown 页面、中英双语。</ktjs-feature>

</ktjs-features>

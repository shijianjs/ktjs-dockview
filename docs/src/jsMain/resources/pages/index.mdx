<ktjs-features section-title="What it wraps" tinted>

<ktjs-feature icon="lucide:layout-dashboard" title="Dock, split, grid, panes">`createDockview`, `createSplitview`, `createGridview` and `createPaneview` — the four layouts upstream exports, each returning its own typed API.</ktjs-feature>

<ktjs-feature icon="lucide:panel-top" title="Panels and groups">`addPanel`, `getPanel`, `removePanel`, `addGroup`, `maximizeGroup` — every member of `DockviewApi`, no dynamic calls.</ktjs-feature>

<ktjs-feature icon="lucide:puzzle" title="A renderer a Kotlin class can implement">`IContentRenderer` is an interface, so `class PanelRenderer : IContentRenderer` is ordinary Kotlin; `init` receives the panel's own API and the dock's.</ktjs-feature>

<ktjs-feature icon="lucide:radio" title="Events as function types">`onDidAddPanel.listen { }` returns a disposer; upstream's callable `Event<T>` is a function type here, never a wrapper class.</ktjs-feature>

<ktjs-feature icon="lucide:palette" title="Themes as values">`themeDark`, `themeLight` and sixteen more are exported objects carrying `className` and `colorScheme`, so a typo does not compile.</ktjs-feature>

<ktjs-feature icon="lucide:book-open" title="Docs in two languages">This site is a Kotlin/JS module built by ktjs-docusaurus: typed configuration, Markdown pages, English and Chinese.</ktjs-feature>

</ktjs-features>
